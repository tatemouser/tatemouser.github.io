Details

Notes.ai is a smart note management platform that transforms audio recordings and handwritten or printed notes into clear, summarized, and searchable digital content. Designed for students, professionals, and researchers, Notes.ai streamlines the process of capturing, organizing, and reviewing information. The app offers real-time transcription, optical character recognition (OCR), and AI-powered summarization — all wrapped in a secure, intuitive interface powered by Google Cloud technologies.

Key Features

  • Secure Google Sign-In using OAuth2 authentication
  • Upload audio or image files directly from the browser
  • Real-time Speech-to-Text transcription powered by Google Cloud
  • Optical Character Recognition (OCR) for handwritten and printed notes using Vision AI
  • Concise AI-generated summaries using Gemini / Vertex AI
  • Organized note grouping with title-based metadata
  • Firebase Firestore database for fast, secure storage and access
  • Built with Angular (frontend) and Node.js (backend), deployed via Google Cloud Run
